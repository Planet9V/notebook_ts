# Plans & Archive

This directory contains all planning artifacts for the Tetrel Notebook project.

## Directory Convention

| Directory | Purpose |
|---|---|
| `docs/plans/` | Active plans, specs, and tracked work items |
| `docs/plans/archive/` | Completed or superseded plans |

## Rules

1. **All planning artifacts go here** — never in the repo root
   - Task lists, brainstorms, specs, implementation plans
   - NOT: README.md, GEMINI.md, CLAUDE.md, CHANGELOG.md (those stay at root)

2. **Archive after feature ships** — move the plan to `docs/plans/archive/` when done
   - Add a completion date comment at the top of the archived file
   - Never delete plans — they are useful historical context

3. **Name files with date prefix** when archiving:
   - `implementation_plan_JUN02.md` not `implementation_plan.md`
